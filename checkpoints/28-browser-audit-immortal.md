# 28 — Браузерный аудит «Бессмертной партии» (2026-11-23)

**Требование:** сыграть партию через РЕАЛЬНЫЙ браузер, две вкладки: сначала 2 гостя, потом 2 зарегистрированных.

**Скрипт:** `test/audit-immortal-browser.mjs` (puppeteer-core + snap chromium; 2 изолированных browser-context = 2 «вкладки»):
- guest: лобби-матчмейкинг, клики по канвасу (squarePx из side_len/offset), по 1 ходу за клик-пару;
- user: sign-up обоих через UI-форму (submitSignUpDetails), затем тот же путь;
- после каждого пли: доски обеих вкладок (через ChessLayout.rotateBoard, маска 0b1111) == локальный референс-борд движка (44 проверки);
- финал: gameEndModal виден, replay-лист 45 строк, реплей-позиция 0 на чёрной вкладке повёрнута, elo-событие (user-режим), ноль pageerror.

**Найдено и исправлено 4 client-бага (ни один не ловился ни socket-аудитом, ни старым E2E):**
1. `game.js` (коммит 32ad04a): click-to-move не сбрасывал is_holding_piece (mousedown хватает_piece при любом нажатии); второй mousedown по ВЗЯТОЧНОЙ клетке хватал чужую фигуру, а ветка «cancelled grab» в render-цикле позже возвращала её на from_position (переопределённый sendMoveToServer) — ПРИЗРАК на доске клиента (e5=81 после exf4). Фикс: клик освобождает grab (mouse+touch), restore маскирует индикаторы.
2. `chessutils.js` (клиент) (32ad04a): валидаторы «линий» считают НЕнульную клетку занятой и getColor(16)=white ⇒ индикаторные биты lastMove на from-клетке (16) блокировали проходы фигур: чёрный ферзь f6→b2 не игрались, т.к. Nd5 оставил на c3 краску 16. Фикс: stripIndicators на входе genMoves/genLegalMoves/isKingInCheck (краска ≠ оккупация).
3. `gameSockets.js` (32ad04a): gameEndModal не открывался НИКЕМ — модалка финала и весь replay-UI были мёртвым кодом; + реплей для ЧЁРНЫХ не доворачивал доску (fen_to_board отдаёт серверную ориентацию). Фикс: showEndModal() во все 5 game-over путей + поворот в applyReplayPosition.
4. `cookieUtil.js` (коммит 5535e77): readCookie возвращал СТРОКУ «name=value» вместо значения (регресс H5-дедупа с 16 авг!) — залогиненный пользователь получал authFailed на /game и вылетал на /index. Гости не задеты ⇒ все прежние guest-тесты были зелёные. Это блокёр любого зарегистрированного игрока в проде.

**Результат на проде (образ a3ab5c73):**
- guest: 9/9 PASS (A=белые, B=чёрные, 45 кликов, мат, модалка, реплей 45, реплей-поворот)
- user: 12/12 PASS (sign-up через UI, лобби-пары, 45 кликов, мат, реплей, elo 1516/1484, 0 pageerror)

**Прочее:** DEBUG=1 на прод включался для диагностики readCookie и снят после (--env-rm). В проде остались тестовые аккаунты imm_user_* / dbg*_ (users.csv на volume; ELO 1500, без партий) — удалять по решению владельца. УРОК: гостевые тесты не покрывают signed-in путь (cookies/sessions) — UI-аудит обязан включать зарегистрированный режим.
